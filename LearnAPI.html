單元進階：免費財經 API 串接與自動化儀表板建構指引

一、 自動化導入理念與教學效益

💡 實務觀點：從「靜態分析」跨越至「動態實時儀表板」

  • 極佳的學習成就感： 讓學生擺脫人工複製貼上，親眼看到自己的專題頁面能自動抓取並顯示最新匯率、國際原油價格與通膨指標。
  • 資安觀念扎根： 學習環境變數管理、API Key（存取金鑰）保護機制，建立不將敏感 key 直接公開發布的正確規範。
  • 實戰非同步開發： 熟練 JavaScript 的 fetch()、async/await、JSON 結構拆解與 DOM 動態渲染技能。

二、 課程專屬：免費財經 API 推薦清單

針對《AI 與經濟分析》課程需求（CPI 預測、總體經濟數據、大宗商品與外匯），精選以下免費、穩定且支援前端跨域（CORS Friendly）的 API 服務：

類別 API 服務名稱 金鑰需求 課程應用與分析範例
總體經濟 FRED API (St. Louis Fed) 免費註冊 Key 直接抓取官方 CPI 歷史數據、聯邦基金利率（Federal Funds Rate）、美債 10 年期殖利率與失業率。
國際匯率 Frankfurter API / ExchangeRate-API 免金鑰 自動抓取 EUR/USD、USD/TWD、USD/JPY 報價，用於觀察匯率對進口物價（Import Price）與核心商品通膨之傳導效果。
大宗商品與市場 Alpha Vantage 免費註冊 Key 抓取 WTI 原油價格（Crude Oil）、天然氣價格與美股盤前數據，做為 10 月能源通膨月增率（MoM）推估的即時指標。
新聞快訊 NewsAPI 免費註冊 Key 透過關鍵字（如 CPI, Inflation, Federal Reserve）即時串接最新英文財經新聞標題，豐富專題頁面動態感。

三、 兩階段實務教學流程設計

第一階段：零門檻體驗（無需 API Key）

使用 Frankfurter API 進行匯率即時抓取，專註於非同步邏輯理解：

  • 計算邏輯展示：
    Fetch(API Endpoint) → Response.json() → Extract(Rate Data) → DOM Render

第二階段：總體經濟與通膨預測儀表板整合

引導學生申請 FRED 或 Alpha Vantage 金鑰，將即時數據整合至 5 頁分析簡報/網頁的第 1 至第 3 頁：

  1. 即時原油價格區塊： 自動更新全美汽油/原油動向，輔助第 2 頁能源與地緣政治分析。
  2. 核心 CPI 歷史趨勢圖： 透過 FRED 自動繪製近期核心 CPI 走勢，協助第 4 頁居住成本黏性剖析。
  3. 匯率與進口物價卡片： 提供即時匯率指數，強化第 3 頁核心商品成本評估。

四、 課堂常見坑洞與資安防範提醒

⚠️ 學生實作重點提醒

  • CORS 跨網域限制： 務必選擇已驗證支援前端跨域存取的公用 API，避開不可直接從瀏覽器呼叫的服務。
  • 金鑰安全保護： 提醒學生切勿將含私鑰的 JavaScript 檔直傳 GitHub 公開倉庫。進階可介紹 Github Pages 結合環境變數或無伺服器代理（Serverless Proxy）。
