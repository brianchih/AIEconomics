🔧 課堂共通除錯重點（Gemini API 模型版本問題）：
多數小組點擊 AI 摘要失敗的原因，是因為程式碼中仍呼叫已廢棄的 gemini-1.5-flash。目前實測最穩定的模型代號為 gemini-2.5-flash（gemini-3.5 偶有不穩定情況），請各組務必至程式碼中更新模型名稱，並將 API Key 妥善存放在 Streamlit Secrets 中（切勿直接寫死上傳至 GitHub）。

📰 二、本週核心教學：NLP 應用與市場輿論情緒分析

過去我們使用 API 抓取的 FRED 與 yfinance 數據皆為「結構化數字」；本週我們跨入「非結構化文本（NLP 自然語言處理）」，透過抓取市場即時新聞與官方聲明，讓 AI 協助判斷市場樂觀/悲觀情緒，以及央行的鷹派（Hawkish，傾向升息緊縮）或鴿派（Dovish，傾向降息寬鬆）立場。

1. 免費與開放的財經文本與情緒數據源

🏛️ 聯準會 FOMC 官方聲明 (免 Key)

判斷央行貨幣政策立場（鷹派 vs 鴿派）最權威的指標，可直接擷取官方聲明文本交由 AI 分析政策風向轉變。

😱 Crypto Fear & Greed Index (免 Key Open API)

提供市場恐慌與貪婪指數的開放 API，可直接透過連線取得量化的市場情緒分數（0~100分）。

📡 Google News / Yahoo News RSS (免 Key)

透過 RSS 串流技術，輸入指定關鍵字（如 Federal Reserve Inflation、TSMC、台積電），即可自動下載最新相關新聞標題。

📊 Finnhub / Alpha Vantage API

專業財經新聞 API，部分原生提供情緒標籤，適合作為與我們自己設計的 Gemini AI 情緒評分進行交叉驗證的基準。

2. 課堂實機示範解析（以「聯準會通膨」新聞為例）

示範流程：透過 RSS 抓取最新 8 條與 Federal Reserve Inflation 相關的新聞標題 ➔ 傳送給 gemini-2.5-flash 進行綜合剖析：

  • 整體情緒分數判定：產出 86 分（高分代表劇烈看空債市與風險資產、強烈鷹派）。
  • 貨幣政策立場研判：多條新聞提及通膨數據高於預期，連立場較溫和的官員也坦言令人不安，市場預期聯準會為控制通膨將採取升息措施，無任何放緩或鴿派訊號。
  • 結構化輸出：自動生成逐條新聞標題的獨立情緒評分與簡評表格，並允許使用者在前端介面自訂提示詞（Prompt）與分析師角色（如總經分析師、股票分析師），加入個人主觀觀點進行客製化報告生成。

🚀 三、進階實作分享：多代理人協作系統 (Multi-Agent System)

👨‍💻 宗諺同學進階架構分享（HTML 前端 + Render 後端 + 多 Agent 協作）

除了課堂基礎的單一 Streamlit 儀表板外，宗諺同學展示了結合 AI 協同編程工具（GPT Codex / CLI）與 Render 雲端平台建置的進階多代理人（Multi-Agent）研究系統：

  • 五位 AI 專業主理人分工架構：
    1. 總管 Agent：負責任務規劃、整合各方證據、協調各 Agent 意見分歧並做出最終報告取捨。
    2. 市場主理人：專責追蹤大盤指數（如加權指數、電子類股指數）與即時價格波動。
    3. 總經主理人：負責分析景氣循環、利率水準與總體經濟數據。
    4. 財報主理人：專門研讀個股（如台積電 2026 季度財報）歷史財務數據與基本面。
    5. 風險主理人：負責檢視潛在風險缺口與市場系統性風險警示。
  • Skill 模組化與資料驗證：透過撰寫結構化的 Markdown 規範與工具腳本（Skills），賦予不同 Agent 專屬的知識庫（RAG）與交叉驗證能力，使用者只需在介面輸入研究問題（如查詢特定公司季報），系統即自動分派任務並生成深度分析。
  • 平台部署與資安提醒：將專案託管於 GitHub 並連動 Render 進行前後端部署（支援帳號登入驗證與後端環境變數儲存 API Key）；老師也特別提醒，系統功能越強大，越需注意 API Key 權限控管與資安防護，避免金鑰外洩。

💻 四、Streamlit 整合版參考程式碼 (app.py)

同學可參考以下完整範例，在既有的 FRED 與 yfinance 儀表板中，加入「NLP 市場新聞與鷹鴿情緒分析」分頁：

import streamlit as st
import pandas as pd
import plotly.express as px
import yfinance as yf
from fredapi import Fred
import feedparser
import google.generativeai as genai
from urllib.parse import quote  # 解決搜尋關鍵字包含空白字元導致的 URL 錯誤

st.set_page_config(page_title="總體經濟、金融與 NLP 市場情緒儀表板", layout="wide")
st.title("🌐 總體經濟、金融指標與 AI 輿論情緒即時儀表板")

# 1. 側邊欄：安全讀取 Secrets 金鑰
st.sidebar.header("⚙️ 設定與金鑰")
fred_key = st.secrets["FRED_API_KEY"] if "FRED_API_KEY" in st.secrets else st.sidebar.text_input("請輸入 FRED API Key:", type="password")

gemini_key = None
if "GEMINI_API_KEY" in st.secrets:
    gemini_key = st.secrets["GEMINI_API_KEY"]
    genai.configure(api_key=gemini_key)
else:
    gemini_input = st.sidebar.text_input("請輸入 Gemini API Key:", type="password")
    if gemini_input:
        gemini_key = gemini_input
        genai.configure(api_key=gemini_key)

# 2. RSS 新聞抓取函式 (支援中英文關鍵字與空白轉碼)
@st.cache_data(ttl=1800)
def fetch_google_news(keyword="Federal Reserve Inflation"):
    safe_keyword = quote(keyword)
    url = f"https://news.google.com/rss/search?q={safe_keyword}&hl=en-US"
    feed = feedparser.parse(url)
    return [entry.title for entry in feed.entries[:8]]

# 3. NLP 市場新聞情緒分析介面設計範例
st.subheader("📰 即時財經新聞與 LLM 鷹鴿派情緒分析")
col_kw, col_role = st.columns([1, 1])
with col_kw:
    search_kw = st.text_input("🔍 輸入關注關鍵字 (例: Federal Reserve Inflation, TSMC):", value="Federal Reserve Inflation")
with col_role:
    analyst_role = st.selectbox("🎭 選擇 AI 分析師視角:", ["專業總體經濟分析師", "華爾街股票投資分析師", "風險控管經理人"])

custom_prompt = st.text_input("✍️ 自訂額外分析指令 (選填):", placeholder="例如：請特別評估對台灣科技股與匯率的潛在衝擊...")

news_titles = fetch_google_news(search_kw)
c1, c2 = st.columns([1, 1])

with c1:
    st.markdown("### 📌 最新相關新聞標題 (RSS)")
    for i, title in enumerate(news_titles, 1):
        st.write(f"**{i}.** {title}")

with c2:
    st.markdown("### 🤖 Gemini AI 情緒評分與報告")
    if gemini_key and st.button("🚀 開始分析市場情緒", type="primary"):
        with st.spinner("AI 正在閱讀新聞並進行鷹鴿派與情緒評估..."):
            news_text = "\n".join([f"- {t}" for t in news_titles])
            prompt = f"你是一位【{analyst_role}】。請針對以下 8 條關於「{search_kw}」的新聞標題進行剖析：\n{news_text}\n\n" \
                     f"額外分析要求：{custom_prompt if custom_prompt else '無'}\n" \
                     f"請以繁體中文輸出結構化報告：\n" \
                     f"1. **整體市場情緒分數**（0~100分，並說明多空/鷹鴿含義）\n" \
                     f"2. **政策或市場立場判定**（鷹派 / 鴿派 / 樂觀 / 悲觀）\n" \
                     f"3. **逐條新聞情緒評分與簡評**（以 Markdown 表格呈現）"
            
            model = genai.GenerativeModel("gemini-2.5-flash")
            response = model.generate_content(prompt)
            st.markdown(response.text)
